# Optional automatic checkout authorization
Version: autopay-v1 | Draft for platform integration

[ ] Enable automatic payment when I select “Finish shopping.”

I authorize charging the saved payment method identified on this screen for the final displayed total of the selected store's shopping basket when I select “Finish shopping.” This is not permission for a charge based solely on location, a barcode scan, elapsed time or leaving a store.

Show the store, payment method label, currency, final total and any configured spending limit before the Finish shopping action. If the total exceeds my limit, the method changes, or further authentication is required, stop automatic checkout and request confirmation.

I can turn automatic payment off in payment settings before finishing a future shopping session. Disabling it does not cancel a payment already submitted; the receipt and store support route must show how to request help or a refund. Declining this authorization leaves manual payment available.

Do not preselect this option or bundle it with required store/shopper terms. Record opt-in and withdrawal events separately; reauthorization is required for material changes to this authorization.

Install Global POS

Install options depend on your browser. Use the instructions below if no install button appears.

Open Global POS in your browser ↗

Android

  1. Open this site in Chrome or another browser that supports web app installation.
  2. Tap “Install app” above when available, or open the browser menu and choose “Install app” or “Add to Home screen.”
  3. Confirm installation and launch Global POS from your home screen.

iPhone and iPad

  1. Open this site in Safari.
  2. Tap Share, then “Add to Home Screen.” Enable “Open as Web App” if offered.
  3. Tap Add and open Global POS from your home screen.

Desktop

In a compatible browser, use the install icon in the address bar or the browser's app installation menu.

What the mobile app does

Discover nearby registered stores, search store addresses and view location-linked inventory. Location permission is optional. Store selection by address works without location access.

Live inventory requires an internet connection. Offline mode shows a connection notice; it does not reuse stock, prices, receipts or payment status. The marketplace offers configured hosted-gateway checkout and isolated simulated payments in the demo. Live payment use requires merchant configuration; camera scanning and exit-verification receipts remain pending.

This release is an installable web app. No Android APK, iOS App Store listing or Google Play listing is provided. Installation requires HTTPS or localhost and a supported browser.

To uninstall, use your device's app or home-screen removal controls. You can revoke location permission in browser or device settings.
